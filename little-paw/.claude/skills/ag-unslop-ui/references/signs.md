# Signs of UI slop (distilled from Unslop UI)
List each found sign as one line with where it lives.

## Color / chrome
- Hue gradients on surfaces, gradient text, colored glows/shadows, radial washes/blobs, neon borders
- Colored chrome competing with content; surfaces reading orange/brown/blue/green in apps
- More than one accent in chrome; more than three text color roles
- Borders not quiet hairlines

## Type / copy
- Exclamation marks, greeting headlines with emoji, ALL CAPS labels with wide tracking
- Hype words: supercharge, seamless, unlock, magic, revolutionize, game-changing, AI-powered everywhere
- Unverified social-proof claims; fake mock numbers like 123,456 or [X]
- Bold 700–900 headings, italic emphasis, gradient text, Inter-as-default with no brand choice

## Icons / badges
- Emoji used as icons or decoration in every label
- Multi-color icons; inconsistent sizes/strokes
- PRO / New ✨ / Beta 🚀 badges that are not required

## Spacing / layout
- One-off spacing (13px, 11px) breaking 4px rhythm
- Everything stacked and centered on a landing with a visual
- App shrunk into a narrow centered column
- Equal-width identical cards with same content kind (template grid)

## Motion / visuals
- animate-pulse/ping on non-live things, shimmer on headings, breathing glows, floating/parallax
- transition-all, hover:scale on cards, purposeless loops
- Decorative blobs, orbs, nebulas, glowing grids, holographic brains/robots
- Richness spread across chrome instead of one or two content moments
