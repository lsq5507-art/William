# World 子项目需求说明 · v0.4

> 日期：2026-11-03（Asia/Shanghai）  
> 产品：Little Paw · 底栏「世界」Tab  
> 设计真源：`/workspace/staff-system/outputs/设计/LP-D-05-world-character-market.md`

## 产品目标

把「世界」从占位做成**宠物社交朋友圈 + 角色市场**的最小完整产品面：用户能浏览生活化动态、点赞评论、看宠物档案、在市场试用/演示获取角色。不接真后端、不接真支付。

## 用户场景

1. 打开世界 → 默认看到 IG 风宠物朋友圈流（≥8 条故事感动态）。
2. 点赞、展开评论、发一条本地评论。
3. 点头像进宠物档案，可关注。
4. 切到「角色市场」试用或演示获取；状态 locked / trial / owned。
5. 切走底栏再回来，World 内子页状态保持。

## 核心流程

```text
浏览朋友圈 → 点赞 / 评论 → 宠物档案（关注）
                ↘ 角色市场 → 试用 / 演示获取
```

## 非目标

真后端、真 IAP、正式意愿日志、改 Feed/Activity/Profile Must、墨意风视觉。
